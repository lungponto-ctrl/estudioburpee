## Como Executar Localmente

1. Certifique-se de ter o Python 3.9+ instalado.
2. Instale as dependências:
   ```bash
   pip install -r requirements.txt
   ```
3. Execute a aplicação:
   ```bash
   python app.py
   ```
4. Acesse no navegador em `http://127.0.0.1:5000`
